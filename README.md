## 首次使用

### 步驟一：準備電腦與手機

1. 使用 Windows x64 電腦，安裝 [Apple Devices／Apple 裝置](https://apps.microsoft.com/detail/9np83lwlpz9k?gl=TW&hl=zh-TW)。[Apple 官方下載說明](https://support.apple.com/zh-tw/118290)
2. 使用**支援資料傳輸**的 USB 線接上 iPhone，保持手機解鎖。
3. 在電腦與手機完成「信任這部電腦」，確認 Apple Devices 能看到手機。[Apple 信任配對說明](https://support.apple.com/en-au/109054)
4. 主程式需要 Microsoft Edge WebView2 執行階段；缺少時從 [Microsoft 官方頁面](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)安裝。

EXE 已包含 Python 與裝置通訊套件，**不用另外安裝 Python，也不用執行環境安裝批次檔**。

### 步驟二：開啟 iPhone 開發者模式

iOS 16 以上請在手機「設定 → 隱私權與安全性 → 開發者模式」手動開啟，依提示重啟，開機解鎖後再確認開啟並輸入密碼。[Apple 開發者模式說明](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)

如果找不到開關：

1. 另外下載並完整解壓縮「開發者模式工具」，保留 EXE 旁的「程式資料」。
2. 接上已信任、已解鎖的 USB 手機，執行 `開發者模式工具.exe`。
3. 選擇手機，按「顯示開發者模式選項」。
4. 回手機完成開啟、重啟與確認，再按工具的「確認已開啟」。

> 工具尚未整合進主程式，不必同時執行。它只顯示選項與讀取狀態；「選項已顯示」不代表「模式已開啟」。已開啟的手機不必重做。首次開啟的完整實機流程尚未驗證，詳見 [工具驗證範圍](DEVELOPER_MODE.md#本版驗證範圍)。

### 步驟三：解壓縮並啟動主程式

下載主程式 ZIP，選擇「全部解壓縮」。第一層應為：

```text
Pikmin launch.exe
程式資料/
```

雙擊 `Pikmin launch.exe`，會開啟獨立桌面視窗。兩者必須放在一起，不要直接在 ZIP 裡執行，也不要只搬走 EXE。

### 步驟四：連接 iPhone

1. 保持手機接線、解鎖，在上方「裝置」選擇 **USB**。
2. 按「連接 iPhone」。一台符合條件的手機會自動連接；多台時先選目標裝置。
3. 若出現本次通道啟動的 Windows 管理員提示，閱讀後確認允許。
4. 等待畫面顯示連線成功，再操作位置或路線。

不必另外執行 `Start_Tunnel.cmd`。**連線成功本身不會傳送座標**；按「套用」、「傳送回家」、操作搖桿或開始路線後，才會依操作更新位置。

### 步驟五：選點或開始路線

- **單點定位：** 切換「選擇位置」，點地圖或輸入「緯度、經度」，確認後按「套用」。
- **路線行走：** 切換「繪製路線」，依序點起點與終點。需要沿道路時選路網並按「沿道路規劃」，檢查路徑後按「選取起點 → 套用」，設定速度再按「開始」。
- **先熟悉操作：** 未連手機時，可在預覽模式畫路線、調速度與預覽，不會改變手機位置。

### 步驟六：結束使用

手機模式按「停止」會停止路線並嘗試清除模擬定位；「停止連接」會嘗試還原定位並中斷連線。最後關閉主程式視窗，程式會清理本次啟動的通道。

拔線、關機或程序被強制結束時，還原指令可能無法送達，請在手機地圖確認實際位置，必要時接回重試。

## 功能說明

| 功能 | 操作方式 | 說明 |
| --- | --- | --- |
| 地圖選點與座標 | 點地圖或輸入緯度、經度，再按「套用」 | 預覽模式更新工作台位置；手機模式傳送所選座標 |
| 手動繪製路線 | 切換「繪製路線」，依序點地圖 | 點之間直接連接；可撤回一點、清除、儲存及選取起點 |
| 沿道路規劃 | 畫 2～25 個途經點，選步行／騎車／開車道路後規劃 | 路網類型與移動速度分開設定 |
| 路線速度與播放 | 選 5／8／12／20 km/h 預設，或輸入 0.5～120 km/h | 支援開始、暫停與續走；顯示距離與預估時間 |
| 循環回程 | 勾選「循環回程」；道路路線需一併重新規劃 | 手動畫線以直線回起點，道路路線沿規劃路徑回程 |
| 方向搖桿 | 拖曳或使用方向鍵，獨立速度 0.5～30 km/h | 離中心越遠越快；放開或失去焦點即停後續移動，保留最後位置 |
| 住家快捷鍵 | 選點後按「設定住家」，要返回時按「傳送回家」 | 設定只儲存座標；回家會套用住家位置。下次啟動也以住家為初始位置 |
| 分類收藏 | 按「＋ 收藏」，選菇點／明信片／純點並命名 | 可篩選分類，超出清單高度可用滾輪捲動；舊收藏未分類時視為純點 |
| 儲存路線與 GPX | 按「儲存路線」，或匯入／匯出 GPX | 本機路線保留道路類型與途經點；GPX 用於交換軌跡座標 |
| 當地時間與時區 | 點地圖或載入收藏位置 | 顯示當地日期、時間、IANA 時區及 UTC 時差，不必套用手機定位 |
| Wi-Fi 連線 | 先 USB 信任與記住手機，再切換 Wi-Fi | 找不到時可填手機目前區網 IP；需既有配對與可連通的同一區網 |

> **「暫停／放開搖桿」、「停止」、「傳送回家」不同：** 前者保留最後模擬位置；手機模式「停止」嘗試清除模擬定位；「傳送回家」套用儲存座標，不是還原真實 GPS。

### Wi-Fi 連線

首次先接上已信任的 USB 手機，切換 Wi-Fi 並依畫面流程記住手機；完成後可拔線測試。手機與電腦保持在同一區網，手機解鎖。找不到時，在 iPhone「設定 → Wi-Fi → 已連線網路旁 ⓘ」查看 IP，填入「手機 IP」後再連接。

v0.7.2 起已修正 Wi-Fi 通道保活回覆，通過拔掉 USB 後連上定位服務的實機檢查；仍受配對、網路與 iOS 狀態影響。IP 變更後需更新欄位。程式不建立新無線配對，也不自動開啟手機 Wi-Fi 偵錯。

### 路線與時區細節

- 道路規劃只有按下按鈕時才把途經點送至 [FOSSGIS／OSRM](https://routing.openstreetmap.de/about.html)。失敗會保留原路線；新增或撤回途經點後需重新規劃。
- GPX 上限 2 MB、10,000 個點，支援單段 track、單條 route 或 waypoint 序列；多段路線會拒絕。只讀取經緯度，不重播原有速度、時間或高度。
- 時區由內建資料判定，不另行上傳選點查詢；時間依電腦時鐘與視窗元件的日光節約時間規則，邊界附近可能有誤差。
- 工作台不讀取手機真實 GPS，也不讀取遊戲的菇點、明信片或其他狀態；收藏分類由使用者自行整理。

## 更新與資料保留

1. 先停止模擬定位並關閉舊版。
2. 下載新版 ZIP，完整解壓縮至新資料夾，執行新版 EXE。
3. 確認新版正常後，再刪除舊版程式資料夾。

**ZIP 不是安裝程式，不會自動覆蓋舊版，也沒有自動更新。** 同一台電腦、同一個 Windows 帳號會使用相同資料位置，收藏、路線與住家可以保留：

```text
%LOCALAPPDATA%/YS-pikmin/data/library.json
```

備份前關閉程式，再複製整個 `data` 資料夾。換電腦或帳號需自行搬移備份。原始碼版預設位於專案的 `data` 資料夾，與 EXE 版不同。

## 常見問題

### 點主程式沒有畫面

確認已全部解壓縮、EXE 與「程式資料」放在一起，且已安裝 WebView2。先關閉仍在執行的舊版再試。診斷紀錄位於 `%LOCALAPPDATA%/YS-pikmin/logs`。

### Apple Devices 看不到手機，或連線失敗

先檢查傳輸線、USB 插孔、手機解鎖與信任配對。能看到手機後，再確認開發者模式及程式錯誤訊息。若缺少開發者映像，在主程式資料夾開啟終端機執行：

```powershell
& ".\Pikmin launch.exe" --prepare-device
```

依提示選手機，下載／掛載可能需要幾分鐘。這與「開啟開發者模式」是不同步驟。

### Windows 顯示「不明的發行者」

目前 EXE 尚未具備程式碼簽章。請核對下載來源與 Release 附的 SHA256；單憑警告或本專案說明，不能判定檔案是否安全。

### 刪除舊資料夾時顯示「程式使用中」

先關閉該版本主程式視窗，等待本次背景通道退出再刪除。由其他工具建立的外部共用通道不會一併關閉。
