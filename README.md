# YS-pikmin · 漫步座標

Windows 上的本機 GPS 路線工作台，版本 **0.7.4**。獨立編寫並附完整可修改原始碼，沒有使用 BloomWalker 的程式碼、品牌或圖片。

## v0.7.4 更新

開啟程式時，地圖、預覽位置與選定座標會以已儲存住家為起點；未設定住家時使用原預設位置，不會自動傳送手機定位。移除頁面上方的標語與說明文字，讓地圖與操作區往上移。本版包含 v0.7.3 的右側地圖模式按鈕調整。收藏、路線與住家沿用原有使用者資料，不需重新設定。

## v0.7.3 更新

「選擇位置／繪製路線」移到右側安排路線面板下方，位於撤回、清除及儲存路線操作上方。原地圖工具列保留回到目前座標與顯示完整路線，兩側底部維持對齊。

## v0.7.2 更新

修正指定 IP 的 Wi-Fi 通道：建立通道前先完成手機的 Marco/Polo 保活交換，連線期間持續回覆並在結束時關閉。另修正 Windows 管理員 helper 結果檔的使用者權限交接。測試裝置 拔掉 USB 後已實測連上定位服務，20 秒後再次連線成功，未傳送座標。此修正已包含在 v0.7.2。

## v0.7.1 更新

方向搖桿縮小至 128px，速度設定改在旁邊；移動控制卡片縮減高度與間距。右側四個路線操作文字放大，兩側面板底部對齊，額外空間優先留給地圖。

## v0.7.0 更新

預設改成獨立 Windows 桌面視窗，不再自動開啟外部瀏覽器或黑色啟動視窗。關閉 YS-pikmin 視窗會停止工作台、嘗試還原定位並清理本次啟動的通道。介面仍在電腦本機運行，地圖圖磚與沿道路查詢仍需網路。需要 Microsoft Edge WebView2 執行階段；本機已安裝，其他電腦若缺少請從 Microsoft 官方安裝。啟動錯誤會顯示訊息，診斷紀錄在 `%LOCALAPPDATA%/YS-pikmin/logs`。

原始碼版另需安裝 `requirements-ui.txt`。`--browser` 可手動使用外部瀏覽器，`--headless`（或舊的 `--no-browser`）只啟動後端供測試。

## v0.6.2 更新

關閉主程式視窗時會自動停止行走、嘗試還原模擬定位並關閉裝置連線。本次由程式啟動的管理員通道以主程式程序控制代碼和心跳監測存活；主程式結束或被強制結束後，通道會自行退出，必要時結束自身程序。既有外部共用通道不會被關閉。關閉瀏覽器分頁不等於結束主程式。手機斷線、系統強制終止或關機時仍可能無法送出還原定位指令，請在手機確認實際位置。

## v0.6.1 更新

地圖加寬、加高，當地時間卡片移到右側欄上方。設定步調與方向搖桿移到地圖下方，以兩張操作卡片呈現；右側保留選點、路線與收藏。窄螢幕自動改為直向排列。

## Windows EXE（不需安裝 Python）

從 GitHub Releases 下載 `YS-pikmin-v0.7.0-Windows-x64.zip`，完整解壓縮，再雙擊 `Pikmin launch.exe`。旁邊的 `程式資料` 資料夾必須保留；不要直接在壓縮檔內執行。這是 Windows x64 版本，啟動後直接顯示獨立桌面視窗；關閉此視窗會結束程式。

EXE 已包含 Python 與 pymobiledevice3 9.29.1。手機仍需 Apple Devices 驅動、信任電腦與開發者模式。按「連接 iPhone」即可啟動通道；Windows 管理員提示需自行確認。開發者映像準備可在命令列執行 `"Pikmin launch.exe" --prepare-device`。

EXE 收藏儲存於 `%LOCALAPPDATA%/YS-pikmin/data`；從原始碼版搬移時，可先關閉程式，再將舊版 `data/library.json` 複製到此資料夾。尚未有程式碼簽章，也未在全新 Windows 電腦完整驗證。

## 原始碼版先試用

1. 解壓縮整個資料夾。
2. 雙擊 **Pikmin launch.cmd**。需要 Python 3.12；製作本版的這台電腦已安裝。
3. 先以 `python -m pip install -r requirements-ui.txt` 安裝視窗元件，啟動後會直接顯示 YS-pikmin 桌面視窗。
4. 在地圖繪製或匯入路線，再點「開始」。保持啟動視窗開啟。

預覽模式不會改變手機位置。即使完全未安裝 iPhone 通訊套件，也能畫路線、預覽、儲存及交換 GPX。

## 已有功能

- 繁體中文介面、OpenStreetMap 地圖、地圖選點與座標輸入。
- 手動畫線、撤回路徑點、清除、路線範圍縮放。
- 透過 FOSSGIS / OSRM 規劃步行、騎車、開車道路；只在按下規劃時查詢。
- 速度設定、開始／暫停／續走、循環回程、累計距離與進度。
- 手動畫線與 GPX 從目前的**工作台座標**接上起點。道路模式要求先套用路線起點，且循環回程必須經過道路規劃，避免額外插入穿越建物的直線。
- 方向搖桿，支援拖曳與方向鍵，速度可獨立調整。
- 收藏位置與儲存路線，保存在程式資料夾的 `data/library.json`。
- GPX 1.1 匯出；單段 track、單條 route、waypoint 序列匯入。
- iPhone 掃描、明確選擇裝置、持續連線傳送座標、停止模擬定位指令。
- 預覽與手機模式分離；傳送失敗即暫停，不會悄悄改成預覽並顯示成功。

## 連接 iPhone

本版實機介接針對 **pymobiledevice3 9.29.1** 的 API 編寫，已檢查本機安裝版本的匯入與指令；**已驗證 USB 掃描、自動通道、定位服務連線及停止模擬定位指令；v0.7.2 已加入拔線後 Wi-Fi 定位服務驗證，尚未驗證遊戲內行走**。不同 iOS 版本、Apple 驅動與開發者映像仍需實測。

1. Windows 安裝 Apple Devices，接上 USB，在 iPhone 選擇「信任這部電腦」，確認 Apple Devices 看得到手機。
2. iOS 16 以上開啟「設定 → 隱私權與安全性 → 開發者模式」，依手機提示重新啟動並確認。
3. 若缺少通訊套件，執行 `Install_Device_Support.cmd`。它只在這個資料夾建立 `.venv` 並安裝指定版本，不更新全機的 Python 套件。本機已有相同版本時可先直接試用。
4. 按「連接 iPhone」會自動準備 iOS 17 以上通道；若出現 Windows 管理員確認，請選擇「是」。不必另外開啟 Start_Tunnel.cmd。
5. 如果連線錯誤指出開發者映像未準備好，執行 `Prepare_Device.cmd`，選擇手機。這會透過 pymobiledevice3 下載／掛載開發者映像，可能需要數分鐘。
6. 只有一部符合連線方式的手機時自動連接；多部時會要求選擇。停止連接可取消等待，或還原定位並中斷裝置連線。背景通道在主程式運作期間可供下次使用，結束主程式時會關閉本次啟動的通道。
7. 選點後按「套用」才會傳送位置；按「開始」才會移動。畫面座標是工作台預覽或最後成功送出的座標，**不會讀取手機真實 GPS**。

USB 與已配對、可由 Apple 服務或 tunneld 偵測到的 Wi-Fi 裝置都能列入清單。第一版沒有自動無線配對、斷線重連或跨網段連線。

## 沿道路規劃

1. 點「繪製路線」，依序選擇起點、途經點及終點，合計 2～25 個點。
2. 選擇「步行道路／騎車道路／開車道路」。這決定道路路網；行走速度仍由「設定步調」控制。
3. 需要回到起點時，先勾選「循環回程」。
4. 點「沿道路規劃」。這一步會把選取的途經點座標送到 [FOSSGIS 的 routing.openstreetmap.de](https://routing.openstreetmap.de/about.html)，該服務會依自身政策保留請求紀錄。
5. 完成後檢查地圖，再按「選取起點 → 套用 → 開始預覽／開始傳送路線」。道路服務可能把選點貼齊附近道路，最多允許 150 公尺；介面會顯示最大的貼齊距離。

規劃失敗時保留原路線，不會自動改成直線。查詢期間仍可按停止，修改路線後舊查詢結果不會覆蓋新路線。每次請求至少間隔兩秒、無自動重試；單次途經點總直線距離上限為 100 公里。這是公共服務，沒有可用性保證。

已規劃的道路路線保留原始途經點；切換道路模式後可以重新規劃。撤回或新增途經點會先轉回手動畫線，需再次按規劃才會更新道路路徑。儲存在「我的收藏」會保留道路類型與途經點；GPX 匯出只有軌跡座標，重新匯入不保留這些設定。

## 結束使用

- 「暫停」保留最後的模擬位置。
- 「停止並還原手機定位」會停止路線並送出清除模擬定位指令；請在手機地圖確認實際位置。
- 完成後點「連接 iPhone → 還原並中斷」，再於啟動視窗按 Ctrl+C；通道視窗也可按 Ctrl+C 關閉。
- 關閉瀏覽器分頁不等於停止背景程式。請先停止行走再關閉。
- 正常 Ctrl+C 結束時會嘗試清除定位。斷線、強制結束、電腦關機時無法保證指令送達；重新接上後重試，必要時重新啟動 iPhone。

## 範圍與限制

- 手動畫線使用大圓距離插值；按「沿道路規劃」才會查詢道路。尚未加入地址搜尋、日夜主題、自訂人物圖片。
- 一份 GPX 最多 2 MB、10,000 個點。多段 track／多條 route 會明確拒絕，避免把不相連的軌跡直接連起來。
- GPX 只使用經緯度；高度、時間戳、原有速度不會重播。移動速度由工作台設定。
- 開始行走時可能需要額外起點與回程點，建議匯入少於 9,999 個點。
- 連線逾時或電腦休眠後不會補走積欠的時間；實際服務延遲可能讓行走比設定速度慢。
- 地圖圖磚需要網路。若服務暫時失效，座標輸入與路線運算仍可使用。
- 這是定位工具的初版，未在 Pikmin Bloom 或其他遊戲內測試，也沒有遊戲狀態讀取、遊戲互動或反偵測功能。

## 資料與依賴

HTTP 伺服器只綁定 `127.0.0.1`。寫入 API 需同來源與每次啟動產生的 token。無雲端收藏、遙測或帳號系統。地圖服務會收到顯示範圍的圖磚請求；道路規劃服務會收到你主動送出的途經點。開發者映像與套件下載另需網路。pymobiledevice3 使用自己的配對記錄及映像快取位置。

收藏採臨時檔加原子替換方式寫入。若資料檔損毀，程式保留原檔並停止覆寫；請先備份後修復。備份 `data` 資料夾即可保留收藏與路線。

原始碼採 **GPL-3.0-or-later**，見 `LICENSE`。Leaflet 為 BSD-2-Clause，完整授權保留於 `web/vendor/LEAFLET-LICENSE`。OpenStreetMap 地圖署名顯示於介面，來源：[OpenStreetMap](https://www.openstreetmap.org/copyright)。裝置介接依據：[pymobiledevice3 專案](https://github.com/doronz88/pymobiledevice3)。

## 開發與驗證

```powershell
py -3.12 start.py --no-browser
py -3.12 -m unittest discover -s tests -v
```

用 `--port 8766` 可更換連接埠；`--data-dir 路徑` 可指定獨立資料目錄。

主程式在 `leafroute/`，前端在 `web/`，裝置介接在 `leafroute/device.py`。預覽運算與裝置 I/O 分離，沒有每次更新都啟動一個 Python 程序。

驗證紀錄見 `TESTING.md`。測試中的手機為替身，不代表真實 iPhone 已通過驗證。


## 地圖當地時間

點選地圖或載入收藏位置時，地圖資訊卡會顯示選定座標的 IANA 時區、當地日期、每秒更新的時間與目前 UTC 時差。不需要套用手機定位。查詢使用隨程式附帶的 @photostructure/tz-lookup 11.7.0（CC0-1.0）；座標不會為此傳送到外部服務。時間依電腦時鐘，日光節約時間規則依瀏覽器資料；時區邊界附近屬近似判定。來源：https://github.com/photostructure/tz-lookup 。授權見 web/vendor/TIMEZONE-LICENSE；查詢程式嵌入 app.js，保留來源於 web/vendor/timezone-lookup.js。


## 住家快捷鍵

在地圖選點，或輸入經緯度後按「設定住家」，只儲存選定座標，不會改變手機位置。住家保存在與收藏相同的 data/library.json，重新啟動仍可使用，再次設定會取代原位置。按「傳送回家」會在預覽中移到住家；已連接 iPhone 時會直接傳送住家座標。行走中需先暫停，斷線時不會假裝成功。這與「停止並還原手機定位」不同，後者才是清除模擬 GPS。住家資料不會加入原始碼上傳。


## 方向搖桿

拖曳搖桿控制方向，可調整 0.5～30 km/h 的獨立速度；離中心越遠速度越接近設定值。放開、失去焦點或切換分頁會停止後續步進，已送出的單次步進可能仍在完成。每次最多移動 0.2 秒的距離，不在伺服器持續排程移動。路線行走時需先暫停才能使用搖桿。搖桿也支援方向鍵；手機模式放開搖桿會保留最後位置，「停止」才會清除模擬定位。


## 收藏類型（本機開發版）

按「＋ 收藏」後，在小視窗選擇菇點、明信片或純點，再輸入名稱儲存。我的收藏會顯示類型標籤，並可篩選指定類型。舊版未分類收藏會顯示為純點。分類只用於本機整理，不會讀取遊戲內容或改變手機定位。


## 指定 Wi-Fi IP（本機實驗功能）

選 Wi-Fi 後可填手機的區網 IP。首次需接上已信任的 USB 手機核對身分，成功讀取無線配對後只保存識別碼與 IP 等裝置資訊，不複製配對憑證。之後可使用原有配對記錄拔線連接。只接受 RFC1918 私有 IPv4，不掃描其他 IP；不建立新配對。

定位通道使用獨立 TCP 輔助程序；取消連線會發出停止訊號，心跳中斷也會結束輔助程序。一般共享通道改用 TCP。v0.7.2 在建立通道前先完成手機 Marco/Polo 保活交換，並持續回覆；已驗證拔除 USB 後可連上定位服務，20 秒後重新連線成功。自動掃描找不到時，請輸入手機目前的區網 IP。程式不會自動開啟手機 Wi-Fi 偵錯。
