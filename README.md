# LeafRoute · 漫步座標

Windows 上的本機 GPS 路線工作台，版本 **0.2.0**。獨立編寫並附完整可修改原始碼，沒有使用 BloomWalker 的程式碼、品牌或圖片。

## v0.2.0 更新

新增步行／騎車／開車的沿道路規劃、道路回程、途經點保留、路線起點選取，以及避免過期查詢覆蓋新路線的檢查。升級時保留原本的 `data` 資料夾，舊版收藏可繼續載入。先在舊版的啟動視窗按 Ctrl+C 結束，再開啟新版；啟動檔會指出仍在執行的舊版本。

## 先試用

1. 解壓縮整個資料夾。
2. 雙擊 **Launch.cmd**。需要 Python 3.12；製作本版的這台電腦已安裝。
3. 程式會在瀏覽器開啟 `http://127.0.0.1:8765`。這是你電腦上的介面，不是上傳到網站。
4. 點「試走一條示範路線」，再點「開始預覽」。保持啟動視窗開啟。

預覽模式不會改變手機位置。即使完全未安裝 iPhone 通訊套件，也能畫路線、預覽、儲存及交換 GPX。

## 已有功能

- 繁體中文介面、OpenStreetMap 地圖、地圖選點與座標輸入。
- 手動畫線、撤回路徑點、清除、路線範圍縮放。
- 透過 FOSSGIS / OSRM 規劃步行、騎車、開車道路；只在按下規劃時查詢。
- 速度設定、開始／暫停／續走、循環回程、累計距離與進度。
- 手動畫線與 GPX 從目前的**工作台座標**接上起點。道路模式要求先套用路線起點，且循環回程必須經過道路規劃，避免額外插入穿越建物的直線。
- 八方向微調，每次 5 公尺。
- 收藏位置與儲存路線，保存在程式資料夾的 `data/library.json`。
- GPX 1.1 匯出；單段 track、單條 route、waypoint 序列匯入。
- iPhone 掃描、明確選擇裝置、持續連線傳送座標、停止模擬定位指令。
- 預覽與手機模式分離；傳送失敗即暫停，不會悄悄改成預覽並顯示成功。

## 連接 iPhone

本版實機介接針對 **pymobiledevice3 9.29.1** 的 API 編寫，已檢查本機安裝版本的匯入與指令；**尚未用實體 iPhone 驗證**。不同 iOS 版本、Apple 驅動與開發者映像仍需實測。

1. Windows 安裝 Apple Devices，接上 USB，在 iPhone 選擇「信任這部電腦」，確認 Apple Devices 看得到手機。
2. iOS 16 以上開啟「設定 → 隱私權與安全性 → 開發者模式」，依手機提示重新啟動並確認。
3. 若缺少通訊套件，執行 `Install_Device_Support.cmd`。它只在這個資料夾建立 `.venv` 並安裝指定版本，不更新全機的 Python 套件。本機已有相同版本時可先直接試用。
4. iOS 17 以上：以系統管理員身分執行 `Start_Tunnel.cmd`，保持通道視窗開啟。程式不會替你自動提權。
5. 如果連線錯誤指出開發者映像未準備好，執行 `Prepare_Device.cmd`，選擇手機。這會透過 pymobiledevice3 下載／掛載開發者映像，可能需要數分鐘。
6. 開啟 LeafRoute，點「連接 iPhone → 掃描裝置」，確認裝置名稱及識別碼末六碼，再點「連接選定裝置」。
7. 選點後按「套用」才會傳送位置；按「開始傳送路線」才會移動。畫面座標是工作台預覽或最後成功送出的座標，**不會讀取手機真實 GPS**。

USB 與已配對、可由 Apple 服務或 tunneld 偵測到的 Wi-Fi 裝置都能列入清單。第一版沒有自動無線配對、斷線重連或跨網段連線。

## 沿道路規劃

1. 點「繪製路線」，依序選擇起點、途經點及終點，合計 2～25 個點。也可先載入示範路線。
2. 選擇「步行道路／騎車道路／開車道路」。這決定道路路網；行走速度仍由「設定步調」控制。
3. 需要回到起點時，先勾選「循環回程」。
4. 點「沿道路規劃」。這一步會把選取的途經點座標送到 [FOSSGIS 的 routing.openstreetmap.de](https://routing.openstreetmap.de/about.html)，該服務會依自身政策保留請求紀錄。
5. 完成後檢查地圖，再按「選取起點 → 套用 → 開始預覽／開始傳送路線」。道路服務可能把選點貼齊附近道路，最多允許 150 公尺；介面會顯示最大的貼齊距離。

規劃失敗時保留原路線，不會自動改成直線。查詢期間仍可按停止，修改路線後舊查詢結果不會覆蓋新路線。每次請求至少間隔兩秒、無自動重試；單次途經點總直線距離上限為 100 公里。這是公共服務，沒有可用性保證。

已規劃的道路路線保留原始途經點；切換道路模式後可以重新規劃。撤回或新增途經點會先轉回手動畫線，需再次按規劃才會更新道路路徑。儲存在「我的收藏」會保留道路類型與途經點；GPX 匯出只有軌跡座標，重新匯入不保留這些設定。

## 結束使用

- 「暫停」保留最後的模擬位置。
- 「停止並還原手機定位」會停止路線並送出清除模擬定位指令；請在手機地圖確認實際位置。
- 完成後點「連接 iPhone → 還原並中斷」，再於啟動視窗按 Ctrl+C；通道視窗也可按 Ctrl+C 關閉。
- 關閉瀏覽器分頁不等於停止背景程式。請先停止行走再關閉。
- 正常 Ctrl+C 結束時會嘗試清除定位。斷線、強制結束、電腦關機時無法保證指令送達；重新接上後重試，必要時重新啟動 iPhone。

## 範圍與限制

- 手動畫線使用大圓距離插值；按「沿道路規劃」才會查詢道路。尚未加入地址搜尋、日夜主題、自訂人物圖片。
- 一份 GPX 最多 2 MB、10,000 個點。多段 track／多條 route 會明確拒絕，避免把不相連的軌跡直接連起來。
- GPX 只使用經緯度；高度、時間戳、原有速度不會重播。移動速度由工作台設定。
- 開始行走時可能需要額外起點與回程點，建議匯入少於 9,999 個點。
- 連線逾時或電腦休眠後不會補走積欠的時間；實際服務延遲可能讓行走比設定速度慢。
- 地圖圖磚需要網路。若服務暫時失效，座標輸入與路線運算仍可使用。
- 這是定位工具的初版，未在 Pikmin Bloom 或其他遊戲內測試，也沒有遊戲狀態讀取、遊戲互動或反偵測功能。

## 資料與依賴

HTTP 伺服器只綁定 `127.0.0.1`。寫入 API 需同來源與每次啟動產生的 token。無雲端收藏、遙測或帳號系統。地圖服務會收到顯示範圍的圖磚請求；道路規劃服務會收到你主動送出的途經點。開發者映像與套件下載另需網路。pymobiledevice3 使用自己的配對記錄及映像快取位置。

收藏採臨時檔加原子替換方式寫入。若資料檔損毀，程式保留原檔並停止覆寫；請先備份後修復。備份 `data` 資料夾即可保留收藏與路線。

原始碼採 **GPL-3.0-or-later**，見 `LICENSE`。Leaflet 為 BSD-2-Clause，完整授權保留於 `web/vendor/LEAFLET-LICENSE`。OpenStreetMap 地圖署名顯示於介面，來源：[OpenStreetMap](https://www.openstreetmap.org/copyright)。裝置介接依據：[pymobiledevice3 專案](https://github.com/doronz88/pymobiledevice3)。

## 開發與驗證

```powershell
py -3.12 start.py --no-browser
py -3.12 -m unittest discover -s tests -v
```

用 `--port 8766` 可更換連接埠；`--data-dir 路徑` 可指定獨立資料目錄。

主程式在 `leafroute/`，前端在 `web/`，裝置介接在 `leafroute/device.py`。預覽運算與裝置 I/O 分離，沒有每次更新都啟動一個 Python 程序。

驗證紀錄見 `TESTING.md`。測試中的手機為替身，不代表真實 iPhone 已通過驗證。
